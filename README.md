# Условия

1. Написать предикат min(List, X), где X — минимальный элемент списка List.
2. Написать предикат sumeven(List, S), где S — сумма чётных элементов списка.
3. Написать предикат countneg(List, C), где C — количество отрицательных элементов списка.
4. Написать предикат secondmax(List, X), где X — второй по величине элемент списка (длина ≥ 2).
5. Написать предикат avg(List, A), где A — среднее арифметическое элементов списка.
6. Написать предикат p(M, X), где X — вектор произведений элементов каждой строки матрицы M.
7. Написать предикат p(M, X), где X — вектор количеств отрицательных элементов в каждой строке матрицы M.
8. Написать предикат p(M, X), где X — вектор сумм чётных элементов каждой строки M.
9. Написать предикат diag(M, D), где D — список элементов главной диагонали квадратной матрицы M
